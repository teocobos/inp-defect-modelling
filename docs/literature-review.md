# Literature Review

## Purpose

This document provides a structured literature-review framework for the InP defect-modelling project.

It should be updated continuously as the project develops.

## Topic 1 — Crystal Structure

Review:

- zincblende InP structure
- lattice parameters
- internal parameter
- temperature dependence
- zincblende InP as a comparison phase

Record authoritative experimental values for validation.

## Topic 2 — Bulk Electronic Structure

Review:

- experimental band gap
- band structure
- band-edge orbital character
- dielectric properties
- effective masses
- known limitations of semilocal DFT

## Topic 3 — Native Vacancies

Review:

- `V_In`
- `V_P`

Focus on:

- formation energies
- stable charge states
- CTLs
- structural relaxation
- localisation
- experimental signatures

## Topic 4 — Antisites

Review:

- `In_P`
- `P_In`

Focus on:

- stability
- reconstruction
- deep levels
- compensation
- charge states

## Topic 5 — Interstitials

Review:

- `In_i`
- `P_i`

Focus on:

- stable configurations
- split interstitials
- migration
- charge states
- metastability

## Topic 6 — Charged-Defect Methodology

Review:

- supercell convergence
- electrostatic corrections
- dielectric treatment
- potential alignment
- band-edge corrections
- finite-size uncertainty

## Topic 7 — Hybrid Functionals

Review:

- HSE-type approaches
- PBE0-type approaches
- tuned hybrid functionals
- band-gap accuracy
- defect-level localisation
- computational cost

## Topic 8 — Experimental Defect Levels

Review experimental techniques including:

- DLTS
- EPR
- photoluminescence
- positron annihilation
- optical spectroscopy

Compare experimentally observed defect levels with calculated CTLs where appropriate.

## Topic 9 — Defect Migration

Review:

- vacancy migration
- interstitial migration
- diffusion mechanisms
- charge-state dependence
- experimental diffusion data

## Topic 10 — Impurities and Dopants

Later literature review should cover technologically relevant impurities and dopants.

Potential examples include:

- H
- O
- C
- Mg
- Si

Selection should be driven by project results and experimental relevance.

## Topic 11 — Device Relevance

Review connections between defects and:

- compensation
- carrier trapping
- leakage
- non-radiative recombination
- reliability
- power-device performance
- optoelectronic performance
